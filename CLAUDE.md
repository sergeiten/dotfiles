## Overview

This is a personal dotfiles repository managed with [dotbot](https://github.com/anishathalye/dotbot). It symlinks config files from this repo into their expected locations in `$HOME`.

## Installing / Applying Changes

```bash
./install          # Run dotbot to apply all symlinks and run shell hooks
```

The `install.conf.yaml` defines:
- Symlinks: maps repo paths → `$HOME` paths (e.g., `.config/nvim` → `~/.config/nvim`)
- Shell hooks: initializes git submodules, regenerates `fzf.zsh`, sets script permissions

Dotbot is included as a git submodule in `./dotbot/`.

## Repository Structure

- `.zsh/` — Zsh config, loaded by `.zshenv` which sets `ZDOTDIR=~/.zsh`. `.zshrc` sources all files in `.zsh/config/` in order: `load.zsh`, `exports.zsh`, `propmt.zsh`, `settings.zsh`, `aliases.zsh`, `widgets.zsh`, `mappings.zsh`, `plugins.zsh`
- `.config/nvim/` — Neovim config (Lua)
- `.config/kitty/` — Kitty terminal config
- `.config/ghostty/` — Ghostty terminal config
- `tmux-sessionizer` — Script installed to `~/.local/scripts/`; fuzzy-finds projects under `~/Developer` and creates/switches tmux sessions

## Neovim Architecture

Entry point is `init.lua`, which loads four modules: `plugins`, `settings`, `keymaps` (colorscheme is commented out).

**Plugin management:** Packer (`wbthomason/packer.nvim`). Plugin configs live in `.config/nvim/lua/plugins/<plugin-name>.lua` and are loaded via `utils/load-plugin-file.lua`.

**LSP:** Configured through Mason + mason-tool-installer. Server-specific configs are in `.config/nvim/lua/lsp/servers/<lang>.lua`. The `mason.lua` plugin config calls `require("lsp.servers")` to bootstrap all servers.

**Formatting:** `conform.nvim` — formats on save. Formatter map: prettier (JS/TS/CSS/HTML/YAML/Markdown/GraphQL), stylua (Lua), goimports (Go), isort+black (Python), rustfmt (Rust), easy-coding-standard (PHP).

**Linting:** `nvim-lint` — triggers on `BufEnter`, `BufWritePost`, `InsertLeave`. Linter map: eslint_d (JS/TS), flake8 (Python, venv-aware), yamllint, stylelint (CSS), phpstan (PHP), golangcilint (Go), vale (Markdown).

**Indentation:** Default 4 spaces. JS/TS/JSON/CSS/HTML/YAML and several others override to 2 spaces via autocmds in `settings.lua`.

**Leader key:** `<Space>`

**Format keymap:** `,f` triggers conform format.

## Zsh Notes

`fzf.zsh` is auto-generated by the install hook (`fzf --zsh > ~/.zsh/config/fzf.zsh`) — do not edit it manually. The `aliases.zsh` defines `config` as a bare git alias for managing this dotfiles repo from anywhere.
